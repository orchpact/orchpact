# Orchpact 0.1.0

Orchpact 是可自托管的组织协作工作流引擎，以独立 Python 包、CLI 与 Docker 构建材料发行。

- 可移植工作流定义、不可覆盖的目录修订、应用固定引用与 Workspace 资源安装。
- 统一任务图、能力授权、独立审校、有界返工与文件交付。
- PostgreSQL 事务、单主进程所有权、原付款人积分预留和真实回执恢复。
- 声明式团队装配与 CrewAI Crew/Task/Agent 协作、受控模型与工具适配、持久化步骤及有界多轮行动。
- HTTP API、Ed25519 应用签名网关、管理台及通用示例。

需要 Python 3.11–3.13、PostgreSQL 18 和配套文件目录。外部 Agent 适配、远程 Worker、多主调度与生成代码执行不在发行范围。

公开范围见 [接口约定](../docs/COMPATIBILITY.md)，可复现验证流程见 [发行验收](../docs/RELEASE_VALIDATION.md)。
